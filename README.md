# Sideme Releases

Official downloads for **Sideme**, clipboard history for macOS, by [Ballmac](https://ballmac.com).

**[Download the latest Sideme for macOS](https://github.com/vamsiy78/sideme-releases/releases/latest/download/Sideme-macOS.dmg)**

- Learn more: https://ballmac.com/sideme
- Requires macOS 14 Sonoma or later

## Install

1. Download `Sideme-macOS.dmg` from the [latest release](https://github.com/vamsiy78/sideme-releases/releases/latest).
2. Open it and drag **Sideme** to the Applications folder.
3. Open Sideme from Applications. macOS asks you to allow it once: click **Done**, then open **System Settings → Privacy & Security** and choose **Open Anyway**. [Step-by-step install guide](https://ballmac.com/sideme/install).

This repository only hosts release builds. Check for Updates in Sideme reads its public list of releases.
